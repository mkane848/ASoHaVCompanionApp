# **The Arc**

## Pick your Quests

Each Arc has a description that should provide the player with a flavorful idea of what type of story they might be able to tell with. Avoid specific class tropes, we want character-driven drama that could apply to any Hero.

### **Starting Quest**

Each Arc comes with a Starting Quest. This helps establish the baseline push towards action that even a new player should be able to follow.

### **Chosen Quest(s)**

Provide a list of additional Quests that fit the Arc that the character may choose as well. Be careful \- taking on too many responsibilities can be quite the burden…
